v0.4.0 — Domínio puro, distância com número

Interno
- Domínio deixou de depender de SwiftUI: os modelos voltaram a ser dado puro,
  e o gradiente do avatar migrou para a camada de apresentação
- Models.swift virou um arquivo por tipo
- Distância deixou de ser o texto "450m" e passou a ser metros em número, o
  que permite ordenar por proximidade e filtrar por raio — a base da busca
  por quem está perto
- Dados de exemplo saíram de dentro dos modelos para a camada Data, para o
  dublê não dividir arquivo com o tipo real quando a API chegar
- 11 para 17 testes
