v0.1.0 — Fundação do projeto

Novidades
- Primeira versão do app com Feed, Perfil, Portfólio do parceiro, Onboarding
  e marcação de disponibilidade

Interno
- Projeto Xcode gerado por XcodeGen a partir do project.yml, com o .xcodeproj
  fora do versionamento
- Alvo de testes com Swift Testing, agrupado por domínio e por feature
- CI no GitHub Actions: build, testes com cobertura, SwiftLint, SwiftFormat e
  validação das mensagens de commit
- Hooks de git versionados para aplicar o padrão localmente
- Padrões do projeto documentados em CONVENTIONS.md
